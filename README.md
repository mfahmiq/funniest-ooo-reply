# Funniest One-Line Out-of-Office Reply

The one-line out-of-office reply your inbox would write if it could:

> Out of office until Monday. My inbox is now in charge, and it has already asked for a raise.

92 characters. The setup is the away message everyone has seen a hundred times; the turn promotes the inbox to acting manager; the punchline gives it a salary dispute on its first day. No beach, no "limited access to email", no full inbox — just the honest truth that while you're away, the mail keeps arriving and the pile does all the work.

## How to run

```sh
python3 main.py
```

This writes the reply verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints exactly the same line to stdout. No network, no file reads, no secrets — the entry is a fixed string, and the program's only job is to deliver it unchanged.
